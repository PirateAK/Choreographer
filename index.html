Show settings

The length a cue is given when it is placed, before it is dragged into shape. These travel with the show, so a reopened file flies and fades the same way. End fade is how long the music takes to come down into an end marker; 0 stops it dead on the moment. Tempo and counts per bar are the music's clock: a phrase is placed by counts of it, and the bars are drawn under the tracks and counted from where the first track begins.

Two bodies closer than 0.55 m — the same test the run-through stops on, but read across the whole show instead of only where the clock happens to run. A fix moves the least it can and re-checks the feet it might pull: it is a normal edit, so Undo puts the path back exactly as it was.
